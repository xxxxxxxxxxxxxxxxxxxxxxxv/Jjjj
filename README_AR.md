# مشروع Warm Media

## محتويات المشروع
- `index.html`: صفحة الموقع وهيكل الواجهة.
- `style.css`: تنسيقات الموقع الأصلية مع إضافات الاستجابة للموبايل والمظاهر.
- `app.js`: منطق المظاهر، القائمة الجانبية، تسجيل الدخول، تحميل الإعدادات والأخبار من Supabase.
- `supabase.sql`: إنشاء الجداول والفهارس وسياسات RLS وStorage.

## تشغيل المشروع محليًا
1. فك ضغط الملف.
2. افتح المجلد في VS Code.
3. شغّل الصفحة باستخدام إضافة Live Server أو أي خادم static محلي.
4. ستظهر الواجهة حتى قبل إعداد Supabase، لكن البيانات الحية وتسجيل الدخول تحتاج إعداد الاتصال.

## إعداد Supabase
1. أنشئ مشروعًا جديدًا في Supabase.
2. افتح SQL Editor والصق محتويات `supabase.sql` ثم نفّذها.
3. من Project Settings > API انسخ Project URL و anon/public key.
4. افتح `app.js` وضع القيم مكان `YOUR-PROJECT` و`YOUR_SUPABASE_ANON_KEY`.
5. لا تضع `service_role` أو أي مفتاح سري في `app.js` أو GitHub.
6. أنشئ حسابًا من واجهة الموقع، ثم استخرج UUID من Authentication > Users.
7. امنح حسابك صلاحية الإدارة من SQL Editor باستخدام أمر UPDATE الموجود في نهاية `supabase.sql`.

## رفعه إلى GitHub
1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع الملفات الأربعة فقط.
3. لا ترفع أي ملف يحتوي مفاتيح سرية أو كلمات مرور.
4. لتشغيله عبر GitHub Pages: Settings > Pages > Deploy from a branch > main > /root.
5. ضع عنوان Supabase و anon key في `app.js` قبل النشر. مفتاح anon مخصص للواجهة العامة ويجب أن تكون حماية البيانات عبر RLS.

## ما يعمل في هذه النسخة
- الحفاظ على واجهة الصفحة الأصلية وفصل HTML/CSS/JS.
- المظاهر الداكن والأبيض والأحمر مع حفظ الاختيار محليًا.
- قائمة جانبية للموبايل، وإغلاقها بالنقر خارجها أو Escape.
- تأثير 3D بسيط على اسم Warm Media وخط Alexandria.
- تهيئة Supabase Auth للتسجيل والدخول.
- تحميل إعدادات الموقع والأخبار المنشورة من Supabase.
- Realtime لتحديث قائمة الأخبار عند تغيّرها.
- مخطط قاعدة بيانات أولي للأخبار والمستخدمين والتفضيلات والإعلانات وغرف النقاش والرسائل والبلاغات.
- Storage buckets وسياسات أولية للملفات.

## حدود النسخة الحالية
الملف الأصلي المرفوع كان صفحة واجهة ثابتة فقط. لذلك لا توجد فيه وظائف قديمة للأخبار أو التعليقات أو غرف النقاش أو لوحة حازم حتى يمكن الحفاظ على تنفيذها. هذه النسخة تضع أساس قاعدة البيانات وبعض الوظائف الأساسية، لكنها لا تدّعي أنها منصة اجتماعية مكتملة.
يلزم استكمال واجهات إدارة الأخبار/المستخدمين/البلاغات وغرف النقاش والرسائل، ورفع الصور من لوحة الإدارة، وإحصاءات الإعلانات، واختبارات E2E فعلية قبل اعتبارها جاهزة للإنتاج.

## تنبيه أمني
سياسات RLS نقطة بداية وليست مراجعة أمنية نهائية. راجعها قبل إطلاق موقع عام، ولا تسمح بكتابة بيانات خاصة أو رسائل حساسة في جداول عامة. لا تعتبر إخفاء الهوية ضمانًا لإخفاء هوية المستخدم عن مسؤولي قاعدة البيانات.
